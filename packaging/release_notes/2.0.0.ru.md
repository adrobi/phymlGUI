### Обзор

В phymlGUI 2.0.0 — новое окно, IQ-TREE как второй движок, интерактивный просмотрщик деревьев и готовые пакеты для Windows и Linux со всеми программами анализа внутри. Программа выравнивает FASTA-файлы MUSCLE и строит деревья максимального правдоподобия в PhyML (последовательно или через MPI) или IQ-TREE (ModelFinder, ультрабыстрый бутстреп) — для отдельных файлов или целых папок.

### Новое окно

- Две панели: слева параметры, недавние файлы, пресеты и история запусков; справа дерево, журнал, статистика, сводка и очередь пакетного режима.
- Светлая и тёмная темы, следующие за системой, с выбором акцентного цвета.
- Все настройки проверяются до запуска, и все ошибки показываются сразу списком.
- Монитор загрузки CPU для системы и для дерева процессов анализа; «Прервать» останавливает всё дерево процессов, включая ранги MPI.

### Просмотрщик деревьев

- Прямоугольная, наклонная и круговая раскладки с сеткой расстояний и шкалой.
- Значения поддержек с подсветкой по порогу, сворачивание клад и укоренение по outgroup.
- Консенсус большинства из бутстреп-деревьев и сравнение двух деревьев по Робинсону–Фаулдсу.
- Экспорт в PNG, SVG и PDF.

### Движки и запуски

- IQ-TREE 2.4.0: ModelFinder подбирает модель (`MFP`); ультрабыстрый бутстреп с минимумом в 1000 реплик; выбранная модель и статистика показываются в окне.
- Пакетный режим с живой очередью по файлам, повтором неудавшихся и сводкой в Excel рядом с CSV.
- История запусков (двойной клик открывает дерево) и пресеты параметров.
- Командная строка без окна: `phymlgui-cli.exe` под Windows, сам AppImage под Linux (`--file`, `--batch`, `--config`, `--version`).

### Пакеты

- Zip для Windows и AppImage для Linux, в каждом PhyML, IQ-TREE, MUSCLE и RAxML-NG; Python не нужен.
- RAxML-NG 2.0.3 теперь собирается под Windows нативно из официальных исходников; результаты совпадают с официальной сборкой для Linux. Он входит в комплект для командной строки; движок в окне запланирован.
- Каждый пакет проверяется перед выпуском: выравнивание и дерево в PhyML и IQ-TREE, MPI-запуск под Linux, открытие окна и AppImage на чистой Ubuntu 22.04.

### Переход с 1.2

- Архив для Windows теперь называется `phymlGUI-<версия>-windows-x64.zip`; распакуйте его в новую папку.
- Чтобы сохранить настройки и историю запусков, скопируйте `phyml_config.json` и `phyml_history.json` из папки 1.2 рядом с новым `phymlgui.exe`. Настройки и история хранятся рядом с программой, если эта папка доступна для записи, иначе в `%APPDATA%\phymlGUI` (Windows) или `~/.config/phymlGUI` (Linux).
- Встроенный PhyML для Windows собран с MPI: Microsoft MPI нужен и для последовательного режима.
