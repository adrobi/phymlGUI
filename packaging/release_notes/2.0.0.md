### Overview

phymlGUI 2.0.0 brings a new window, IQ-TREE as a second engine, an interactive tree viewer and ready-to-run packages for Windows and Linux with all analysis programs included. The program aligns FASTA files with MUSCLE and builds maximum-likelihood trees with PhyML (serial or MPI) or IQ-TREE (ModelFinder, ultrafast bootstrap), for single files or whole folders.

### New window

- Two panes: the parameters, recent files, presets and run history on the left; the tree, log, statistics, summary and batch queue on the right.
- Light and dark themes following the system, with an accent colour.
- Every setting is checked before a run, and all problems are listed at once.
- A live CPU monitor for the system and for the analysis process tree; Cancel stops the whole process tree, MPI ranks included.

### Tree viewer

- Rectangular, slanted and circular layouts with a distance grid and a scale.
- Support values with threshold highlighting, clade collapsing and rerooting on an outgroup.
- Majority-rule consensus from bootstrap trees and Robinson–Foulds comparison of two trees.
- Export to PNG, SVG and PDF.

### Engines and runs

- IQ-TREE 2.4.0: ModelFinder chooses the model (`MFP`); ultrafast bootstrap with the 1000-replicate minimum enforced; the chosen model and the statistics are shown in the window.
- Batch mode with a live per-file queue, retry of the failed files and an Excel summary next to the CSV one.
- Run history (a double click reopens a tree) and parameter presets.
- Command line without the window: `phymlgui-cli.exe` on Windows, the AppImage itself on Linux (`--file`, `--batch`, `--config`, `--version`).

### Packages

- Windows zip and Linux AppImage, each with PhyML, IQ-TREE, MUSCLE and RAxML-NG; Python is not required.
- RAxML-NG 2.0.3 is now built natively for Windows from the official sources; its results match the official Linux build. It is included for the command line; an engine in the window is planned.
- Every package is tested before release: alignment and a tree with PhyML and IQ-TREE, an MPI run on Linux, the window opening, and the AppImage on a clean Ubuntu 22.04.

### Upgrading from 1.2

- The Windows archive is now `phymlGUI-<version>-windows-x64.zip`; unpack it into a new folder.
- To keep your settings and run history, copy `phyml_config.json` and `phyml_history.json` from the 1.2 folder next to the new `phymlgui.exe`. Settings and history are kept next to the program when that folder is writable, otherwise in `%APPDATA%\phymlGUI` (Windows) or `~/.config/phymlGUI` (Linux).
- The bundled PhyML for Windows is an MPI build: install Microsoft MPI also for serial runs.

The full list of changes is in [CHANGELOG.md](https://github.com/adrobi/phymlGUI/blob/master/CHANGELOG.md).
